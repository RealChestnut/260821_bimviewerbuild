# BIM 4D Viewer — 시험판 안내

버전 0.1.0 · 2026-09-07

읽는 데 3분, 해 보는 데 15분입니다. **무엇이 안 되는지 알려 주시는 것이 목적**이므로, 잘 안 되면 그게 성공입니다.

---

## 1. 이 프로그램이 하는 일

IFC 모델을 열고, 공정(Task)을 만들고, 부재를 공정에 연결한 뒤, **시간을 움직이면 그 시점의 시공 상태를 3D로 보여 줍니다.**

특정 BIM 저작 도구에 매이지 않습니다. Revit이든 ArchiCAD든 Tekla든 IFC로 내보내면 됩니다.

## 2. 설치

두 가지 중 받으신 것으로 하시면 됩니다.

**설치 프로그램** — `Bim4dViewer-Setup-0.1.0.exe`를 두 번 누릅니다. 80 MB이고 깔면 300 MB 정도 씁니다. 시작 메뉴에 등록되고 `.bim4d` 파일이 연결되며 제거 프로그램이 생깁니다.

**ZIP** — `Bim4dViewer-0.1.0.zip`을 원하는 폴더에 풀고 `Bim4d.Desktop.exe`를 두 번 누릅니다. 설치가 아니라 폴더 하나가 전부입니다. 지울 때는 폴더를 지우면 됩니다. **WebView2 런타임이 없으면 앱이 그 사실과 받는 곳을 알려 줍니다.** ZIP 안의 안내문에 자세히 적혀 있습니다.

**Windows가 경고를 띄웁니다.**

```
Windows에서 PC를 보호했습니다 — 알 수 없는 게시자
```

아직 코드 서명 인증서를 사지 않아서 그렇습니다. **추가 정보 → 실행**을 누르면 됩니다. 찜찜하면 설치하지 마시고 알려 주세요.

관리자 권한이 막혀 있으면 명령 프롬프트에서 이렇게 하면 자기 계정에만 깔립니다.

```
Bim4dViewer-Setup-0.1.0.exe /CURRENTUSER
```

.NET이나 Python은 따로 깔 필요 없습니다. 안에 다 들어 있습니다.

## 3. 15분 과제

**자기 프로젝트의 IFC로 해 주세요.** 그게 이 시험의 핵심입니다. 없으면 아무 IFC나 괜찮습니다.

1. **파일 ▸ IFC 열기** — 자기 모델을 엽니다
2. 모델을 **돌리고 확대**해 봅니다. 부재를 **클릭**하면 GlobalId와 속성이 보입니다
3. 왼쪽 트리에서 층·공간을 눌러 봅니다. **숨기기·격리·단면**을 써 봅니다
4. 일정을 만듭니다 — Task를 몇 개 추가하고 날짜를 넣습니다
5. 3D에서 부재를 고른 뒤 **Task에 연결**합니다
6. **시간을 움직여** 그 부재가 나타나고 사라지는지 봅니다
7. **파일 ▸ 프로젝트 저장** (Ctrl+S) → 프로그램을 **완전히 닫습니다**
8. 저장한 `.bim4d` 파일을 **두 번 눌러** 다시 엽니다. 모델·Task·연결·화면이 그대로인지 봅니다

7~8번이 이번에 새로 만든 부분이라 특히 봐 주시면 좋습니다.

## 4. 꼭 알려 주셨으면 하는 것

한 줄씩이면 충분합니다.

| 무엇 | 왜 |
| --- | --- |
| **어느 도구로 IFC를 뽑았는지** — 이름과 버전, 내보내기 설정 | 도구마다 IFC가 다릅니다. 지금 확인된 것은 Revit 하나뿐입니다 |
| **모델 크기** — 파일 MB, 대략 부재 수 | 여는 데 얼마나 걸렸는지와 함께 |
| **안 열리거나 이상하게 보이면** 그 화면 | 축척이 이상하다, 원점에서 멀리 떨어져 있다, 부재가 안 잡힌다 등 |
| **헷갈린 지점** | 버튼 이름이 무슨 뜻인지 몰랐다, 어디를 눌러야 할지 몰랐다 |
| **없어서 못 쓰겠는 기능** | 이게 다음에 무엇을 만들지를 정합니다 |

## 5. 지금 없는 것 (알고 있습니다)

없다고 알려 주실 필요는 없지만, 다른 게 없으면 알려 주세요.

- **주말·공휴일 계산이 없습니다.** 기간은 달력 날짜 그대로입니다
- **자동 일정 계산이 없습니다.** 선행을 미뤄도 후행이 따라 밀리지 않습니다. 저장하고 검사만 합니다
- **되돌리기(Ctrl+Z)가 없습니다.** 실수하면 저장 전이라면 다시 열어 주세요
- **자동 저장이 없습니다.** 되돌리기가 없어서 일부러 넣지 않았습니다. Ctrl+S를 눌러 주세요
- **자동 업데이트가 없습니다.** 새 버전은 파일로 다시 드립니다
- 원가(5D), 여러 사람 동시 작업, 클라우드, 모바일은 이번 범위가 아닙니다

## 6. 문제가 생기면

**프로그램이 무엇을 했는지 기록이 남습니다.**

```
도움말 ▸ 기록 폴더 열기
```

그 폴더의 **그날 날짜 파일**(`shell-20260907.log`)을 보내 주시면 대부분 원인이 바로 나옵니다. 줄마다 무엇을 했는지가 적혀 있습니다.

**모델 파일은 보내지 않으셔도 됩니다.** 기밀이면 안 보내시는 편이 낫고, 기록만으로 모자라면 그때 여쭙겠습니다.

프로그램이 멈추거나 창이 사라지면 그 사실만 알려 주셔도 됩니다.

## 7. 안전한 것

- **원본 IFC를 고치지 않습니다.** 읽기만 합니다
- 프로젝트 파일(`.bim4d`)에도 **IFC를 담지 않습니다.** 파일 위치와 지문만 적습니다. 그래서 모델을 옮기면 다시 물어봅니다
- 인터넷으로 아무것도 보내지 않습니다. 기록도 이 PC에만 남습니다
- 제거해도 설정과 최근 목록은 남습니다. 완전히 지우려면 `%APPDATA%\Bim4dViewer` 폴더를 지우시면 됩니다
